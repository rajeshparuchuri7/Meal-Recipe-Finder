# 🍽️ Meal Recipe Finder

A responsive web application that allows users to search meals, browse recipes by category, and view detailed cooking instructions using TheMealDB API.

##  Features

- 🔍 Search meals by name
- 🍲 Browse meals by category
- 📖 View complete recipe details
- 🥗 Ingredients and cooking instructions
- ▶️ YouTube cooking tutorial links
- 📱 Fully responsive design
- 🎨 Modern and user-friendly interface

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- TheMealDB API
